Key findings

  • Harness alone moves the needle. suite_v1: 6.3% → 100% without touching weights.
  • Few-shot is the first cliff. P0→P1 jumps +62 pp on suite_v1.
  • Tools ≠ magic. P4 is flat vs P3 on suite_v1; ReAct (P5) and self-refine (P6) matter more here.
  • Easy suites lie. After 100% on suite_v1, paper suite_v2 peaks at 48.4% (P7).
  • Negative result: P8 gated REPL regresses (−7.8 pp) on suite_v2 vs P7 — MiniCPM emits broken tool XML on full MBPP implement prompts.
